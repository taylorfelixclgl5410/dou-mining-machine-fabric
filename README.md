## What DouMiningMachine Does

DouMiningMachine is a Fabric-based Minecraft mod for automating recurring mining, digging, and excavation work. Its machine-oriented tools let you manage block removal with configurable operating range and speed, while also providing options for handling the resulting materials.

Rather than changing general gameplay, the mod concentrates on practical excavation tasks. You can select ores or other materials for filtering, direct collected items to chests, and choose between clearing a single layer or excavating an entire chunk.

## Core Capabilities

- Mining and excavation machines created specifically for Minecraft
- Built for the Fabric platform
- Configurable machine range
- Configurable processing speed
- Coal-based operating model
- Automatic delivery of collected items to chests
- Filtering for ores and other materials
- Same-layer excavation
- Full-chunk excavation
